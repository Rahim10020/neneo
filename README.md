# neneo?

Smart fare estimates for moto and taxi rides in Lomé — built for locals first.

## Overview

neneo? helps you instantly estimate a fair price for your rides in Lomé, whether you take a `zemidjan` (motorbike taxi) or a classic taxi.
The app is designed for everyday commuters, students, and professionals who want transparent pricing before they negotiate.

## Key Features

- Real-time fare estimates based on distance and vehicle type
- Automatic night and weekend multipliers for more realistic prices
- Support for both moto and taxi with different base rates in CFA
- Clean, mobile-first UI optimized for low-end Android devices
- Local experience: tuned for Lomé with default map coordinates
- Simple settings: choose your default vehicle, language, and trip history options

## Tech Stack

- Flutter & Dart
- Provider for state management
- Geolocator for precise location access

## Getting Started

1. Make sure you have Flutter installed (`stable` channel recommended).
2. Clone this repository.
3. Run `flutter pub get`.
4. Start the app with `flutter run`.
